## พฤติกรรม

ถ้า query เป็นตัวเลขล้วนตั้งแต่ 2 หลักขึ้นไป `searchThaiAddress` จะส่งต่อไปยังการค้นหาด้วยรหัสไปรษณีย์โดยอัตโนมัติ ไม่ต้องเรียกฟังก์ชันแยก แต่ถ้าต้องการเรียกใช้ตรง ๆ ก็ทำได้ผ่าน `lookupByZipCode(index, zip)`

ผลลัพธ์จะเรียงให้รายการที่ตรงรหัสแบบเป๊ะ (exact match) ขึ้นก่อนเสมอ จากนั้นตามด้วยรายการที่ตรงแบบขึ้นต้นด้วย (prefix match) เรียงจากรหัสน้อยไปมาก

## ค่าเริ่มต้นของ `zipLimit`

รหัสไปรษณีย์หนึ่งรหัสสามารถครอบคลุมได้หลายตำบล เช่น `45000` ครอบคลุมถึง 33 ตำบล และจากรหัสไปรษณีย์ทั้งหมด 953 รหัสในระบบ มีถึง 230 รหัสที่ครอบคลุมมากกว่า 10 ตำบล

ถ้าจำกัดรหัสที่พิมพ์ครบด้วย `limit` ของการค้นหาแบบข้อความ (ปกติคือ 10) ตำบลที่ถูกต้องจำนวนมากจะถูกซ่อนไปโดยไม่รู้ตัว ดังนั้นเมื่อไม่ได้ส่ง `zipLimit` มา `searchThaiAddress` จะคืนตำบล**ทั้งหมด**ของรหัสที่ครบ 5 หลัก จึงเป็นเหตุผลที่ demo ด้านบนตั้งค่าเริ่มต้นเป็น `45000` ไว้ — เพื่อให้เห็นผลลัพธ์จำนวนมากนี้ได้ทันทีที่หน้าโหลด

แต่ prefix ที่พิมพ์ไม่ครบต่างออกไป เช่น `30` อย่างเดียวตรงกับประมาณ 290 ตำบล ค่าเริ่มต้นของ prefix 2–4 หลักจึงจำกัดที่ `limit` เพื่อไม่ให้ query สั้น ๆ ครั้งเดียวคืนผลลัพธ์หลายร้อยรายการ (สำคัญเมื่อเปิดการค้นหาผ่าน endpoint ฝั่ง server) ถ้าต้องการผลทั้งหมดให้ส่ง `zipLimit: Infinity` หรือส่งตัวเลขเพื่อกำหนดเพดานเอง ส่วนการเรียก `lookupByZipCode` ตรง ๆ จะไม่ถูกจำกัดจนกว่าจะส่ง `zipLimit`

```ts
import { lookupByZipCode } from 'thaizip'

lookupByZipCode(index, '45000') // exact
lookupByZipCode(index, '450')   // prefix scan
```
