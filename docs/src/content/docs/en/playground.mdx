## Things to try

- Drag `threshold` down and watch the result count grow — a lower minimum score lets looser queries count as matches.
- Turn off `romanizationAliases` and type `lardprao` — the results disappear because that spelling doesn't match the RTGS form in the dataset directly. Turn it back on and try again.
- Search postal code `45000` and toggle `unlimited zipLimit` on and off to see how many valid subdistricts get hidden when the result count is capped.
